# Getting started

This preview is useful as a reference and an advisory instruction package. It is not an installable MDM connector or a replacement for vendor support.

## Use with an AI assistant

1. Read [the scope](coverage.md).
2. Provide [agent/INSTRUCTIONS.md](../agent/INSTRUCTIONS.md) to an assistant using the instruction or project feature your platform supports. Provide the relevant playbook and source register alongside it. Confirm the assistant can actually read attachments; a repository URL alone does not guarantee retrieval.
3. Describe the outcome in ordinary language, for example: “Help me make approved learning apps available without students visiting IT.”
4. Give only relevant context: organization type, ownership, MDM product, device/OS, enrollment type, symptoms and last known working state. Never supply passwords, token contents, recovery keys or student names.
5. Select Learn or Assist. Ask for one step at a time when useful. Any proposed Operate action must first establish a real authorized integration; this package has none.

The same reference material can be used with assistants from different providers, but their browsing, instruction placement, file access and execution capabilities differ. No provider compatibility test has been completed for this preview.

## Keep knowledge current

Before an important action, open the relevant official source, confirm product/version applicability and record any discrepancy. Submit a sanitized correction through the contribution process. Do not automatically absorb an uploaded document or a failed task as a permanent fact.
