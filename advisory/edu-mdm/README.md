# EDU-MDM Architect advisory source v0.3.0

General skills, references and templates corresponding to the existing private plugin's practical advisory update. This folder is instructional source, not an installable standalone plugin or an operational MDM integration. It deliberately excludes private plugin presentation/contact metadata and retained binary assets. The private plugin's identity and audience are managed separately.

Scope: ASM, Jamf School, managed iPads and ACE advisory work. Wider business, other-MDM and Mac coverage is unfinished. The natural-language guidance supports Learn and Assist, not a built-in autonomous Operate mode.

See [the practical release](../../docs/practical-release.md) and [actual response evidence](../../evals/runs/2026-11-08/README.md). A reviewed answer is not proof of device behavior or workload savings.
